# Personal portfolio feature plan

Status: Draft | 2026-10-19

**Purpose.** A Vercel-hosted React portfolio with Python content serving, presenting Samuel Tsao's systems and ML work to hiring teams. No CMS, live feeds, contact form or public chatbot. Add an owner-only AI Gateway routing experiment; quota/errors leave recruiter paths unaffected.

**Experience.** Home introduces Samuel and offers View work / Resume. Continue through 3 selected project or experience stories, career highlights, About/education, resume, and contact. Each story has a shareable page: problem, personal contribution, approach, tradeoffs, evidence, limitations, and verified code/demo links. Visitors inspect work, download a resume, or connect via LinkedIn/email.

**Content.** Lead with the asset recommendation engine; support with production impact from Human Interest and Nursa, labeled experience stories when code is private. Show skill groups tied to evidence, SJSU AI master's study (2027 expected), and UCSD CS degree. Use shareable claims; no unproven benchmark wins. See content inventory.

**Presentation.** Use clean editorial typography, restrained color, technical diagrams, mobile layouts, and minimal motion.

**Acceptance.** Within 30 seconds, visitors can identify specialization, inspect one contribution, and find a connection action. All primary paths work by keyboard and phone. Content appears without a spinner; missing images retain text, absent demos omit links, unavailable resume offers contact, and unknown routes offer Home. Email has a copy fallback with feedback; do not claim delivery.

**Edges.** Check malformed/duplicate links, stale roles, missing assets, long titles, narrow screens, zoom, contrast, reduced motion, interrupted downloads, offline/retry, and partial page loads. Keep private links and secrets off-site.

**Open.** Confirm featured repositories, public email/resume, and shareable employer claims.
