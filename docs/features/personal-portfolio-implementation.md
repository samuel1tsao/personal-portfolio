# Personal portfolio implementation plan

Status: Proposed | 2026-10-19 | React + Python + AI Gateway

**Stack.** Only docs exist. Add `frontend/` Next.js/React, TypeScript, CSS Modules, pnpm; `backend/` FastAPI, Pydantic, httpx, pytest, locked dependencies. Two Vercel projects share the repo; frontend rewrites `/api/v1/*` to Python. Validate routing/preview pairing in a deployment spike. No CMS/database.

**Data/API.** Git-owned `backend/content/portfolio.json` is canonical. `backend/models.py` validates profile, roles, education, stories (slug, kind, title, summary, contribution, evidence, links, publication state, order). Reject duplicate slugs/order, bad dates/URLs, unsafe assets; exclude drafts/private notes. Public `GET /api/v1/portfolio` returns `{schema_version,content_revision,profile,stories}` including bodies; `GET /api/v1/stories/{slug}` returns story/404. Errors: `{error:{code,message},request_id}`; 422 invalid input, 503 unavailable. GETs are idempotent; incompatible schema -> `/v2`. No migrations, transactions, writes, pagination/filtering.

**Flow/files (proposed).** `backend/app.py` routes -> `content_service.py` validated content -> JSON. `frontend/src/lib/api.ts` fetches revision-matched content for prerendering `app/page.tsx` and `app/work/[slug]/page.tsx`; `generateStaticParams` enumerates published stories. Build uses explicit `CONTENT_API_URL`, matching backend commit, with protected-preview credentials server-side. Timeout 5s, one GET retry; mismatch/failure rejects build and preserves prior release. Content edits deploy backend then frontend. Python also serves runtime reads; core content never depends on client loading. Components supply stories, timeline, diagrams, contact; unknown/draft routes return 404.

**UX/search.** Preserve editorial recruiter layout. Initial HTML includes content, metadata, canonical, safe Person/ProfilePage JSON-LD. `frontend/src/lib/seo.ts`, `app/robots.ts`, `sitemap.ts`, `opengraph-image.tsx` use validated `SITE_URL`. `frontend/public/` holds reviewed assets. Text/links work without JS; copy failure offers selectable email. Protect/noindex previews, allow production search crawlers. No ranking promises.

**AI experiment.** Owner-only CLI: `backend/scripts/route_prompt.py` -> `backend/gateway.py` -> `POST https://ai-gateway.vercel.sh/v1/chat/completions` with server secret `AI_GATEWAY_API_KEY`. Prompt <=2000 chars plus allowlisted route alias -> text/model/usage/request ID. Select two free-tier-eligible model IDs at setup; alias routing with at most one eligible fallback for known provider failure. Max output 256 tokens, 20s total deadline; no retry on ambiguous timeout. Clear validation/auth/quota/upstream errors; no keys or prompts in logs. No tools/uploads/public inference endpoint. Free-credit details in companion brief; hosted UI needs later auth/shared-quota design.

**Hosting.** Pin supported runtime versions; validate FastAPI function limits. No durable local writes. Configure backend URL, rewrites, paired preview URLs, HTTPS/domain and per-environment secrets. Deploy compatible backend first, check revision/schema, then frontend. Retain paired rollback releases and slug redirects. Hosting/Gateway quotas are separate; no auto top-up.

**Checks.** Lint/types/build; pytest valid/empty/malformed/duplicate/stale/oversized/partial content, drafts, escaping. Mock API 404/422/503, timeouts/retry/revision mismatch/recovery. Mock Gateway success/401/429/5xx/exhaustion, invalid aliases, token limits, fallback counts, ambiguous timeout; no paid CI calls. E2E links/404/PDF/copy denial, no JS, keyboard/axe, zoom, 320/768/1440px, reduced motion. Inspect HTML/schema/robots/sitemap, rewrites, preview auth/secret isolation. Targets: mobile Lighthouse >=95, JS <=150KB gzip; field LCP <=2.5s, INP <=200ms, CLS <=0.1. Smoke 20 concurrent reads/repeat deploys; no shared mutable state. Observe build/API failures, revision, latency, tokens/credits and indexing. Gates: domain, repos, public assets/evidence, model eligibility. Ranking/crawl delays are external risks.
