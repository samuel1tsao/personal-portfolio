Reported COCO/KITTI mAP values are 0.471/0.303 for YOLO11n, 0.581/0.349 for YOLO11m, and 0.578/0.366 for RT-DETR. These are not standard 80-class COCO results or scores on KITTI's official test split; the README says fine-tuning and GPU memory measurement were not performed.
